# Bhasha Motion

An original multilingual motion-design inspiration library, inspired by the *structure* of prompt-motion.com without copying its brand, content, videos, or creator submissions.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework: **Vite**. Build command: `npm run build`. Output directory: `dist`.
4. Deploy. Optionally connect your custom domain in Vercel project settings.

## Current scope

- Responsive React/Vite frontend, nine original animated CSS examples.
- Search, category filters, prompt/skill filters, preview pause, prompt detail drawers, copy-to-clipboard.
- Language selector with Hindi and English fully authored interface dictionaries; 10 additional Indian language choices use English fallback pending human-reviewed translations.
- Prompt content currently in English to remain usable with AI tools.
- Demo content is stored in `src.jsx`; no CMS, accounts, database, submission form, video hosting, or real newsletter backend.

## Production next steps

Move content and translations into a CMS, commission native-language translations, add authentic demo videos with creator permissions, implement submission moderation and newsletter backend, accessibility audit, SEO localization, and analytics.
